# Agent Instructions

This repo gives an AI agent control of a real Android phone over ADB.

- **To operate the phone for any task**, follow [`skills/phone-control/SKILL.md`](skills/phone-control/SKILL.md). Start with `local-bridge/phonectl health`.
- **To run the autonomous QA agent**, follow `qa-agent/RUN.md` (see `CLAUDE.md` for the full layout).
- **First-time setup** (adb, USB debugging, starting the bridge): `setup/SETUP.md`.
